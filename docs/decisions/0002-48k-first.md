# 0002: Start with one 48K profile and earn accuracy incrementally
Status: accepted. Date: 2026-10-08.

## Context
Supporting every Spectrum clone immediately multiplies memory, ULA, interrupt and audio behaviors.
A quickly playable checkpoint is useful, but must not hide accuracy limits.

## Decision
Implement Spectrum 48K first with a documented NMOS Z80/ULA Issue 3 profile.
Design intra-instruction bus timing from the beginning. Ship a clearly limited initial
RAM-based renderer before full contention/raster/floating-bus fidelity.
Use 48K snapshots before tape loading so early games need fewer subsystems.

## Alternatives
128K-first gives more games but complicates paging/AY. Perfect raster accuracy before any
playable UI delays useful feedback. Instruction-only CPU timing makes later correction harder.

## Consequences
Early compatibility is narrow and documented. Timed bus structure is required in M1 even when
waits are initially absent. Clone/model behavior cannot be encoded as unexplained global toggles.

## Verification
Maintain per-stage evidence and per-profile tests. Preserve event ordering as contention and
raster fidelity are introduced; use snapshot/CPU/machine regressions to detect changes.
